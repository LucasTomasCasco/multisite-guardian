# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include the plugin version, the WordPress and PHP versions, the steps to reproduce, and the impact you expect.

I aim to acknowledge reports within 72 hours and to publish a fix or a mitigation before disclosure.

## Scope

In scope: the plugin code in this repository, its REST routes, WP-CLI commands, admin pages, report exports and the Docker demo's defaults.

Out of scope: vulnerabilities in WordPress, PHP, MySQL or MariaDB themselves, and the demo environment's local credentials, which are documented as sandbox-only.
